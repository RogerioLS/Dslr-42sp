# Peer Evaluation Defense Guide

During evaluation, you must be prepared to answer:
1. **Mathematical derivations**: Explain how the cost function derivative is obtained.
2. **Feature selection justification**: Point to the pair plot / scatter plot / histogram charts and explain why certain features were kept and others dropped (e.g. collinearity, uniform distributions).
3. **Hyperparameters**: Explain learning rate $\alpha$, number of epochs, normalization choice (Z-score vs Min-Max) and convergence curve.
4. **No-cheating verification**: Walk the evaluator through `src/analytics/statistics.py` showing handcrafted sum/mean/variance/percentile implementations.
